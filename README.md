# Monitor Test Utility
Monitor Test Utility is a free Windows application to test display sanity. It is portable and not installation required.

### Download
Download the latest version from the [Releases](https://github.com/Javad-Taheri/MonitorTestUtility/releases/latest) section.

### System Requirements
Windows Vista or later <br>
Windows XP is no longer supported after v3.0.0

### License
Monitor Test Utility is free to use.
